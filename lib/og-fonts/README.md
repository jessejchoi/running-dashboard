Fonts for the Boss Raid share card (`app/api/groups/[id]/raid/card`), read from disk at runtime and bundled via `outputFileTracingIncludes` in `next.config.js`.

- `Syne-Bold.woff`: Syne 700, latin subset, from Fontsource. SIL Open Font License 1.1.
- `SpaceMono-Regular.ttf`, `SpaceMono-Bold.ttf`: Space Mono by Colophon for Google Fonts. SIL Open Font License 1.1.
